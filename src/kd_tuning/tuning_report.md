# Tita 轮关节 kd_vel 整定报告

## 1. 结论
- 基准 kd_vel: 0.01
- **最优 kd_vel: 0.002**
- 合理有效区间: 0.001 ~ 0.005 (0.0 亦可用, 机身姿态稍差)
- 对应关节: 左轮 joint_left_leg_4 / 右轮 joint_right_leg_4 (共用同一 kd_vel)
- 单位: Nm/(rad/s^2) (力矩 / 关节加速度), 依据控制律 tau = kp_vel*(v_des-v) - kd_vel*(v_t-v_{t-1})/0.005

## 2. 选择依据
- 轮速 RMS: 0.002 均值 0.92/0.92 rad/s, 较基准 1.90/2.13 下降约 52%/57%;
- 机身稳定性: 0.002 的 ang_vel RMS (0.15/0.27) 为所有候选最优 (基准 0.53/0.98);
- 恢复成功率: 所有候选 86~89% 无显著差异 (0.05 为 12.5%, 不可用);
- kd >= 0.01 时未滤波速度差分噪声被放大: 0.02 轮速 RMS 4.0/3.7, 0.05 达 18.5/19.5 且几乎丧失恢复能力;
- kd=0.0 (纯P) 轮速 RMS 1.25/1.14 次优, 但机身角速度 RMS (0.34/0.55) 明显差于 0.002, 说明小量 D 项仍有助于抑制高频抖动;
- 正负切换次数各候选波动大 (单次困难姿态可到 145~202), 均值上 0.005(45.5) < 0.002(72.9) ~ 0.0(74.2) < 基准(113.5); 综合 RMS/机身/切换三维度取 0.002。

## 5. 指标定义
- 重置检测: 相邻采样 |dgx|+|dgy| > 0.5 (重力投影突跳); 回退固定10s网格;
- 恢复完成: hypot(gx,gy) < 0.15 连续保持 0.5s;
- 零速条件: |v| < 0.1 rad/s (双轮) 连续保持 0.5s;
- 稳定段: 恢复完成时刻至下一次重置; 正负切换死区 ±0.1 rad/s;
- 依据: 50Hz 采样、轮速噪声水平 ~0.05-0.2 rad/s, ε=0.1 约为噪声上限, T_h=0.5s=25 采样足以排除瞬时过零。

## 6. 局限
- CSV 未含力矩/目标速度, 力矩饱和率与 D 项力矩未直接验证 (间接由轮速振荡推断);
- 启动段(首次重置前)与末尾截断段已从统计排除;
- kd=0.008 因连续三次仿真启动失败未采集 (位于已测 0.005 与 0.01 之间, 不影响结论);
- 实验为无头仿真 (gzclient 未运行), 视觉确认由人工 Gazebo 观察补充。
